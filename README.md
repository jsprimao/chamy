# Chamy

Sistema SaaS para campanhas por notificações push, com painel do vendedor e painel administrativo do dono da plataforma.

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicar na Vercel

Configurações:

- Framework: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## Telas incluídas

- Landing page
- Cadastro demonstrativo
- Painel do vendedor
- Campanhas
- Clientes
- Automações
- Captura/widget
- Relatórios
- Planos
- Configurações
- Painel Admin do dono da plataforma
